1. システム概要

本アプリは、草野球プレイヤーが試合ごとの打席・投手成績を記録・集計するためのWebアプリケーションである。モバイルファーストのUIで設計されており、試合当日のリアルタイム入力から、シーズン通算成績の分析まで一貫して対応する。

1.1 主要機能

⚾ 打席記録
打席結果（安打・アウト・出塁等）、打球方向、打点・得点・盗塁を入力。内野安打・エラー・FCの守備位置まで記録可能
⚾ 投手成績記録
登板イニング数、勝敗・セーブ・ホールド、被安打・奪三振・四球・自責点等を記録
📊 成績集計（打撃）
打率・出塁率・長打率・OPS・IsoD・IsoP・RC27など高度な指標を自動算出
📊 成績集計（投手）
ERA・WHIP・K/9・K/BB・FIPを自動算出
📋 ダッシュボード
最近の試合結果と今シーズン主要成績をサマリー表示
🎯 打球方向分析
打球方向チャート（グラフィカル表示）
📅 マルチシーズン
シーズン単位での成績管理・切り替え

3.3 データ層（Supabase / PostgreSQL）

全テーブルにRow Level Securityを有効化し、auth.uid() = user_id の条件でユーザー固有データのみアクセス可能とする。

7. 成績計算ロジック

lib/stats.ts に実装。すべてクライアントサイドで計算される純粋関数。

打撃成績（calcBattingStats）

打数 (AB)
PA − BB − HBP − 犠打 − 犠飛
打率 (AVG)
H / AB
出塁率 (OBP)
(H + BB + HBP) / (AB + BB + HBP + 犠飛)
長打率 (SLG)
塁打 / AB　（1B×1 + 2B×2 + 3B×3 + HR×4）
OPS
OBP + SLG
IsoD
OBP − AVG
IsoP
SLG − AVG
RC27
((H+BB+HBP) × TB / (AB+BB+HBP)) × 27 / (AB − H + CS)

投手成績（calcPitchingStats）

投球回（innings_pitched）は 1/3イニング単位の整数で保存。例: 3回0/3 = 9、3回1/3 = 10、3回2/3 = 11。 ERA等の計算時は outsToIPDecimal() で小数換算してから使用する。
ERA
(自責点 / IP) × 9
WHIP
(被安打 + 四球) / IP
K/9
(奪三振 / IP) × 9
K/BB
奪三振 / 四球
FIP
(13×HR + 3×(BB+HBP) − 2×K) / IP + 3.10
勝率
勝 / (勝 + 敗)

8. 認証フロー

Supabase Auth の OAuth / Magic Link フローを Next.js Middleware と組み合わせて実装。

ログインフロー

ユーザー操作
/login でOAuth / Magic Link を選択してボタンをクリック
Supabase認証
Supabase Auth がプロバイダー認証ページへリダイレクト
コールバック受信
/auth/callback に認証コードが届く。exchangeCodeForSession() でセッションCookieを発行
ユーザーテーブル作成
初回ログイン時、DBトリガー on_auth_user_created が public.users レコードを自動生成
ダッシュボードへ
/dashboard へリダイレクト。以降はCookieでセッション維持

ミドルウェア認証ガード

保護対象/(protected) 配下の全ルート
未認証リクエスト/login へ自動リダイレクト
認証済み → /login/dashboard へリダイレクト
セッション更新Middleware でリクエストのたびにCookieを自動更新（@supabase/ssr）
