1. システム概要

本アプリは、草野球プレイヤーが試合ごとの打席・投手成績を記録・集計・分析するための PWA 対応 Web アプリケーションである。モバイルファーストのUIで設計されており、試合当日のリアルタイム入力から、シーズン通算成績の分析・マルチシーズン比較まで一貫して対応する。9種類のテーマ（球団カラー含む）をユーザーが自由に選択可能。

1.1 主要機能一覧

⚾ 打席記録
打席結果・打球方向・打点・得点・盗塁を入力。内野安打方向・エラー守備位置・フィールダーズチョイスを詳細記録。ボールカウント記録対応
⚾ 投手成績記録
登板イニング数・勝敗セーブホールド・被安打/本塁打・奪三振・四球死球・失点/自責点・球数を記録
📊 成績集計（打撃）
打率・出塁率・長打率・OPS・IsoD・IsoP・RC27を自動算出。シーズン累計/試合別/打席ログ/方向/分析の6タブ表示
📊 成績集計（投手）
ERA（7回制換算）・WHIP・K/9・K/BB・FIP 自動算出。デュアルラインチャートで推移表示
📋 ダッシュボード
シーズン成績サマリー・チーム戦績・直近5試合・連続安打ストリーク・実績バッジ・目標打率メーター
🎯 打球方向分析
外野5方向 + 内野6ポジション対応のグラフィカル打球方向チャート
📅 マルチシーズン
シーズン単位での成績管理。ダッシュボードセレクター・複数シーズン比較グラフ・前シーズン比サマリーカード
🏆 マイルストーン
9種のバッジ（.300打者・5/10HR・10打点・10盗塁・OPS .800+/.900+・20安打・無三振10打席）初達成時にトースト通知
🌟 テーマ切替
9テーマ: ライト/ダーク/自動 + ABM/NTD/HNF/HTG/TYS/TRG。球団カラーテーマは公式サイト実測値
📷 PWA対応
ホーム画面追加・オフライン打席記録（IndexedDB キュー）・Service Worker キャッシュ対応
💾 CSV エクスポート
試合別・打席別データを CSV ファイルとしてダウンロード
📢 SNS コピー
シーズン成績をリッチテキストでクリップボードにコピー（Twitter/LINE 等に貼り付け可能）
✏ 試合メモ
試合ごとにひとことメモを記録・編集（games.notes カラム活用）
🔑 クライアントキャッシュ
SessionStorage ベースの QueryCache でページ再読み込み時のネットワークリクエストを削減

4. デザイントークンシステム v2.0.0 刷新

v2.0.0 より CSS カスタムプロパティ（変数）主体のデザイントークン体系に移行した。各テーマは globals.css で .light / .dark / .abema 等のクラスごとに変数を定義し、tailwind.config.ts で bg-lv1 / text-accent 等の Tailwind クラスに紐付ける。

ハードコードカラー禁止: bg-blue-500 / style={{ color: '#xxx' }} は使用不可。必ずデザイントークン（bg-theme, text-accent 等）を使用すること。

4.3 テーマ切替システム

app/(protected)/_components/ThemeProvider.tsx が Context API でテーマ状態を管理。

管理する状態theme: 'light' | 'dark' | 'system' | 'abema' | 'nintendo' | 'hnf' | 'htg' | 'tys' | 'trg'
永続化localStorage（キー: 'theme'）
適用方法document.documentElement.className にテーマクラスを設定。tailwind.config.ts の darkMode: 'selector' が各クラスのトークン変数を参照
system設定window.matchMedia('prefers-color-scheme: dark') を監視。OS設定変化にリアルタイム追従
設定画面/settings のテーマセクションから3×3グリッドボタンで切替

5. ナビゲーション設計

app/(protected)/_components/Nav.tsx に実装。モバイルとデスクトップで異なるレイアウト。

モバイル（〜lg）画面上部ナビバー。ロゴ + ダッシュボード・試合・成績（左）＋ 設定・ログアウト（右）
デスクトップ（lg〜）左固定サイドバー lg:fixed lg:w-60。絵文字アイコン付きリンク

9. 成績計算ロジック

lib/stats.ts に実装。すべてクライアントサイドで計算される純粋関数。

打撃成績（calcBattingStats）

打数 (AB)
PA − BB − HBP − 犠打 − 犠飛
打率 (AVG)
H / AB
出塁率 (OBP)
(H + BB + HBP) / (AB + BB + HBP + 犠飛)
長打率 (SLG)
塁打 / AB（1B×1 + 2B×2 + 3B×3 + HR×4）
OPS
OBP + SLG
IsoD
OBP − AVG
IsoP
SLG − AVG
RC27
((H+BB+HBP) × TB / (AB+BB+HBP)) × 27 / (AB − H + CS)

投手成績（calcPitchingStats）

投球回（innings_pitched）は 1/3イニング単位の整数で保存。ERA計算時は outsToIPDecimal() で小数換算。ERA は7回制換算（× 21/27 相当）を採用。表示は formatIP() で「3.1」形式。
ERA（7回制換算）
(自責点 / IP) × 7 × 3（草野球7回制対応）
WHIP
(被安打 + 四球) / IP
K/9
(奪三振 / IP) × 9
K/BB
奪三振 / 四球
FIP
(13×HR + 3×(BB+HBP) − 2×K) / IP + 3.10
勝率
勝 / (勝 + 敗)

13. DBマイグレーション履歴

001_initial_schema.sql
初期スキーマ。users / games / at_bats / pitching_stats テーブル。RLS・インデックス・DBトリガー（on_auth_user_created）設定
002_add_infield_positions.sql
at_bats.direction カラムに内野守備位置（pitcher / catcher / first_base / second_base / third_base / shortstop）を追加。内野安打方向の詳細記録に対応
003_add_rbi_count_stolen_base.sql
at_bats に rbi_count（打点数）/ stolen_base_count（盗塁数）/ is_caught_stealing（盗塁死フラグ）を追加。複数打点・複数盗塁の記録に対応
004_add_season_to_games.sql
games テーブルに season（INTEGER、年度）カラムを追加。マルチシーズン成績管理に対応。既存レコードには作成年を自動補完
005_add_liner_out.sql
result_type の ENUM に liner_out（ライナーアウト）を追加。打球方向チャートの OUT_TYPES に対応
006_add_fielding_position.sql
at_bats に fielding_position カラムを追加。守備位置別成績集計（分析タブ）のデータソースとして使用
007_add_count_balls_strikes.sql
at_bats に count_balls（INTEGER）/ count_strikes（INTEGER）カラムを追加。打席ごとのカウント記録に対応
