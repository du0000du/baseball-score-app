1. システム概要

本アプリは、草野球プレイヤーが試合ごとの打席・投手成績を記録・集計するためのWebアプリケーションである。モバイルファーストのUIで設計されており、試合当日のリアルタイム入力から、シーズン通算成績の分析まで一貫して対応する。ダークモード・ライトモードをユーザーが自由に切替可能。

1.1 主要機能

⚾ 打席記録
打席結果（安打・アウト・出塁等）、打球方向、打点・得点・盗塁を入力。内野安打・エラー・FCの守備位置まで記録可能
⚾ 投手成績記録
登板イニング数、勝敗・セーブ・ホールド、被安打・被本塁打・奪三振・四球・死球・自責点・球数を記録
📊 成績集計（打撃）
打率・出塁率・長打率・OPS・IsoD・IsoP・RC27など高度な指標を自動算出。5タブで多角的に表示
📊 成績集計（投手）
ERA・WHIP・K/9・K/BB・FIPを自動算出
📋 ダッシュボード
最近の試合結果と今シーズン主要成績をサマリー表示
🎯 打球方向分析
打球方向チャート（グラフィカル表示）
📅 マルチシーズン
シーズン単位での成績管理・切り替え
🌙 テーマ切替 NEW
ライト・ダーク・システム設定に対応。設定画面から切替可能
✏️ 試合編集 NEW
登録済み試合の日付・対戦相手・スコア・メモを後から編集可能

3.3 データ層（Supabase / PostgreSQL）

全テーブルにRow Level Securityを有効化し、auth.uid() = user_id の条件でユーザー固有データのみアクセス可能とする。

テーブル構成

テーブル名主なカラム説明

4.3 テーマ切替システム

ThemeProvider（app/(protected)/_components/ThemeProvider.tsx）が Context API でテーマ状態を管理する。

管理する状態theme: 'light' | 'dark' | 'system'
永続化localStorage（キー: 'theme'）
適用方法document.documentElement.classList の dark クラス追加/削除
system設定window.matchMedia('prefers-color-scheme: dark') を監視し、OS設定変化にリアルタイム追従
設定画面/settings のテーマセクションから切替。☀️ ライト / 🌙 ダーク / 💻 システム設定の3択ボタン
